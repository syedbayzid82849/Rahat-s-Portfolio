# Rahat Hussain - AI Portfolio Website

[Live Site](https://rahat-hussain.netlify.app/)

---

## Overview

This is the personal portfolio website of **Rahat Hussain**, a professional graphic designer specializing in branding, social media design, and digital design solutions. The website showcases Rahat's skills, projects, services, and expertise in a clean, modern, and responsive layout.

The site is built using **React**, **Framer Motion**, **Tailwind CSS**, and integrates contact form functionality with **EmailJS**.

---

## Features

- **Hero Section**: Engaging introduction with animated profile image, social media links, and key statistics.
- **About Me**: Detailed professional bio highlighting experience, skills, and approach.
- **Skills & Expertise**: Interactive skills progress bars and expertise list.
- **Portfolio**: Showcase of top projects with project details, categories, and interactive hover effects.
- **Services**: Detailed service cards with pricing, delivery, and descriptions.
- **Contact Section**: Fully functional contact form with EmailJS integration, validation, and toast notifications.
- **Responsive Design**: Mobile-first design with smooth animations for all sections.
- **Smooth Scroll**: Navigation links and "Back to Top" button with smooth scrolling.
- **Accessibility & SEO**: Proper semantic HTML, meta tags, and headings for SEO optimization.

---

## Technologies Used

- **React.js** - Frontend framework
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Animations
- **React Scroll** - Smooth scrolling
- **EmailJS** - Contact form email handling
- **React Hook Form** - Form validation
- **React Hot Toast** - Form notifications
- **React Helmet** - Dynamic meta tags and SEO
- **Lucide & React Icons** - Icons throughout the site
- **Netlify** - Deployment and hosting
